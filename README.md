# QR-Passport Viewer

Страница-просмотрщик для QR-паспортов оборудования.

QR-код содержит ссылку вида `?data=<base64url(JSON)>` — страница декодирует
данные и отображает карточку. Фотографии лежат в каталоге `photos/`
и загружаются туда автоматически программой QR-Паспорт через GitHub API.

Опубликовано через GitHub Pages: https://dukawb.github.io/qr-passport-viewer/
